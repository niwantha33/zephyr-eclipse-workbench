Explore generated Devicetree evidence

Search by path, compatible string or label. Choose a node to inspect its generated Devicetree record. Double-click a graph card, or select a navigator result, to centre its neighbourhood. Drag a graph block to rearrange it; lines follow the block. Focus a block and use arrow keys to nudge it (Shift+arrow for smaller steps). Reset layout restores the original positions. Dragging is only a temporary visual arrangement: it does not change Devicetree, saved project settings or firmware, and it resets on refresh or when opening another graph. On the background, drag to pan. When the canvas has keyboard focus, arrow keys pan the graph; + and − zoom, F fits, ? opens help, and Escape closes help.

Solid lines represent observed hierarchy. Dashed lines represent parser-resolved references. Enabled is a Devicetree configuration status, not electrical wiring, a running driver or live hardware state. Unknown status is never treated as enabled.
