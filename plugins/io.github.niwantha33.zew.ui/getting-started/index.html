Getting started

Work through the steps in order, or jump to any step. Instructions appear on the right.

Step 1 of 7

Step 1 · Project

Open or create a project

What
Create a Zephyr application, or import an existing one.
How
Open the wizard, then select the project in Project Explorer.

Step 2 · Hardware

Choose your hardware

What
Choose the exact board and processor target for your project.
How
Browse available boards, then confirm the saved target in Project Properties.
Note
Browsing does not change the selected board.

Step 3 · Configuration

Configure your firmware

What
Inspect devicetree connections, overlays, Kconfig and enabled peripherals.
How
Start with guided hardware, then open advanced RTOS and build settings when needed.
Note
Changing configuration requires an explicit action and a rebuild.

Step 4 · Build

Build your firmware

What
Compile the active board and build profile.
How
Build, then check the Console and Problems views for diagnostics.
Note
A local ELF file does not prove that firmware ran on the device.

Step 5 · Flash & Debug

Run on your board

What
Program a connected board or start a debugging session.
How
Connect the correct debug probe and verify the selected target first.
Note
Flashing and debugging can reset or alter hardware. Selecting this step does neither.

Step 6 · Inspect & Analyse

Inspect firmware behaviour

What
Inspect traces, thread scheduling and CPU activity when evidence is available.
How
Start with Debug Trace Console, then view captured timeline and CPU-load evidence.
Note
Missing or offline captures are not live target data.

Step 7 · More Tools

Explore additional tools

What
Inspect project configuration, connected YAML and supported target registers.
How
Choose a specialised tool when you need its evidence.
Note
Unavailable registers and build evidence remain unavailable, not guessed.
