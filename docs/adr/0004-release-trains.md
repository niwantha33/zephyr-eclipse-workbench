# ADR-0004 — Versioning and release gates
Status: proposed (2026-10-30).

G0 market and baseline, G1 deterministic Diagnose, G2 compliance evidence, G3 upgrade impact, G4 agent and CI, evaluated in order. G0 not yet passed. Each release train has independent versions, fixtures, negative controls, exact-head CI, hardware evidence states and explicit approval. No automatic production publication, certification, savings or universal SoC claims. Existing v0.1.21-preview.1 remains the public release until separately authorised.
