# Trace analysis capabilities

> This table is the single source of truth. Do not describe a feature as supported in any other document unless it appears here with status Implemented.

**This table is the single source of truth for trace analysis capability claims in this repository.**

Scope: features currently on `main` as of 2026-11-07, including the memory profiler merged in PR #196. Draft or unmerged pull requests are not counted as implemented. A feature marked **Partial** may display only evidenced input and must not infer missing events, timestamps, ownership or resource usage.

Here **Validated against real hardware** means that the complete named analysis feature was checked with physical target trace input. Generic firmware builds, installed UI smoke tests and the previously observed MSPM0 RAM CTF capture do **not** establish that validation for the listed analysis views. `No` on the licensing/IDE rows means hardware validation is not applicable, not that the license or Eclipse components are absent.
